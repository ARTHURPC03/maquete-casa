# Maquete da casa do Cacupé

Maquete 3D da casa, com as propostas de mobília, o orçamento e as fotos de antes e depois:
**https://arthurpc03.github.io/maquete-casa/**

## Para trabalhar com o Claude

1. Clone o repositório: `git clone https://github.com/ARTHURPC03/maquete-casa.git`
2. Abra a pasta no Claude Code (app ou `claude` no terminal).
3. Peça em português, por exemplo: "troca o sofá da sala de estar por um de 3,2 m em couro", "põe uma terceira
   mesa de poker no salão" ou "refaz o orçamento com a opção cinema".

O `CLAUDE.md` explica para o Claude como o projeto é montado e como publicar. Para publicar direto na `main`
é preciso ser colaborador do repositório. Quem não é pode abrir um pull request.
